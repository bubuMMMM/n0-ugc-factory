# Mechanism compatibility reference

This file is deliberately compact. The examples supplied by the product owner are training references, not lines to reuse.

| Mechanism | Strong visual matches | Brand signals |
| --- | --- | --- |
| drama | shocked, embarrassed, sad, frustrated | pain, objection, costly mistake |
| story | thoughtful, calm, proud, curious | job, journey, lesson, case |
| credential | calm, skeptical, proud | proof, expertise, real credential |
| insider | curious, surprised, skeptical | differentiator, process, closed-world knowledge |
| numbered | pointing, presenting, calm | useful value, checklist, mistakes |
| diagnostic | skeptical, confused, thoughtful | pain, symptom, objection |
| inversion | deadpan, skeptical | belief, misconception, contrarian fact |
| overheard | confused, skeptical, laughing | FAQ, customer language, objection |
| confession | embarrassed, relieved, thoughtful | mistake, lesson, pain |
| pov | expressive scene, action | job, recognizable moment |
| value | calm, positive | benefit, how-to, practical payoff |
| take | deadpan, proud, frustrated | opinion, rule, category expertise |
| fourthwall | eye contact, playful reaction | viewer context, social-native observation |
| transformation | happy, proud, relieved | verified before/after, outcome |
| wall | slow thoughtful reaction | layered pain, realization |
| proof | pointing, showing object/screen | review, result, credential, artifact |
| product_natural | demonstration, product use | product benefit, workflow, proof |

Second lines must earn their place by adding tension, scope, or specificity. They must not be generic “listen closely” filler.
